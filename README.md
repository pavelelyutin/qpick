# QPICK

Тестовое задание: интернет-магазин наушников с каталогом, корзиной, избранным
и оформлением заказа. Реализован на React с использованием React Router
и sessionStorage для хранения состояния.

## Демо

[qpick-vrn.vercel.app](https://qpick-vrn.vercel.app)

## Технологии

- **React 18** — UI
- **React Router v6** — маршрутизация
- **Vite** — сборщик
- **SCSS + БЭМ** — стилизация
- **react-i18next** — локализация (Рус / Eng)
- **sessionStorage** — хранение корзины, избранного и языка

## Функциональность

### Каталог
- Две секции товаров: проводные и беспроводные наушники
- Карточка товара: изображение, название, цена, старая цена (если есть скидка), рейтинг
- Кнопка «Купить» - добавляет товар в корзину
- После добавления кнопка превращается в счётчик `−/+`
- Кнопка-сердечко - добавление в избранное
- Иконка информации - открытие модалки с подробной информацией

### Корзина
- Список добавленных товаров с изображением, названием и ценой
- Изменение количества через `+/−`
- Счётчик в шапке
- Удаление товара
- Итоговая сумма
- Пустая корзина - отдельное состояние

### Избранное
- Отдельная страница со списком избранных товаров
- Счётчик в шапке
- Удаление из избранного кликом по сердечку

### Оформление заказа
- Модальное окно с формой: имя, телефон
- Валидация полей
- Собщение об успехе после оформления
- Очистка корзины после успешного заказа

### Общее
- Адаптив (мобильные, планшеты, десктоп)
- Переключение языка `Рус / Eng`
- focus, hover, active на всех интерактивных элементах
- Хранение состояния в `sessionStorage` (корзина, избранное, язык)

## Запуск

### dev
```bash
# Клонировать репозиторий
git clone https://github.com/pavelelyutin/qpick.git

# Перейти в папку проекта
cd qpick

# Установить зависимости
npm install

# Запустить dev-сервер
npm run dev
```

### build
```bash
# Собрать проект
npm run build

# Запустить проект
npm run preview
```

## Что можно улучшить

- **State management:** сейчас корзина, избранное и язык хранятся
на уровне `App` и передаются через пропсы. Переход на `Context` или `Redux Toolkit`.
- **Типизация:** проект на JS.
- **Тесты**: `Vitest`
- **Маска для телефона**: сейчас телефон валидируется регуляркой, но без автоформатирования. Добавить маску `+7 (999) 999-99-99`
- **Фокус в модалках:** фокус перемещается внутрь модалки
при открытии и возвращается при закрытии, но Tab может выйти
за её пределы.
